## 第零章 核心方法论与套路

这门课最值钱的不是单题，而是几套可迁移的方法论。面试时能讲清楚"我用的是哪一套套路"比背答案更重要。

### 1. 二分查找的三种形态
- **存在性**：找到即返回。
- **找边界**：找 `>=target` 的最左 / `<=target` 的最右——找到后**不要停**，继续向对应方向收缩并记录答案。
- **无序找局部最小**：利用"两端 + 中点"的趋势关系二分（不要求有序）。
- 中点统一写 `mid = L + ((R - L) >> 1)` 防溢出。

### 2. 递归（分治）套路
任何分治问题写成 `process(范围)`：
1. base case（最小范围）；
2. 把大问题拆成子问题，调用自身；
3. 用子问题结果组合答案。
（如求最大值、归并、快排、汉诺塔都是这个骨架。）

### 3. 二叉树「树形 DP」套路（**面试核心，必背**）
适用于"答案可以由左右子树的信息推出"的所有树问题：
1. 假设以 X 为头，**列出向左、向右要的信息**；
2. 把左右要的信息**求并集**，定义统一的 `Info` 结构体；
3. 写递归：先递归拿到左右 `Info`，再用它们 + X 自身**加工出 X 的 Info** 返回；
4. base case 返回 `null` 或空 Info，注意空指针。

> 例：判断 BST（要 min/max/isBST）、判断平衡（要 height/isBalanced）、最大 BST 子树、最大距离、聚会最大快乐值（要 yes/no 两个状态）。**全是同一套路换信息。**

### 4. 暴力递归 → 动态规划「四步走」（**DP 部分的灵魂**）
课程反复强调：**不要直接想 DP，先写出正确的暴力递归，再机械地改成 DP。**
1. **写暴力递归**：可变参数尽量少、用基本类型表达"还剩什么没决定"；
2. **改记忆化搜索**：加一张缓存表（dp / HashMap），命中直接返回——**几乎不动逻辑**；
3. **改严格表结构 DP**：分析可变参数范围 → 建表 → 找 base case 填入 → 看递归依赖**确定填表顺序** → 用代码替代递归调用；
4. **斜率/窗口/前缀和优化**：观察某个 for 循环枚举是否可被前缀和、单调队列、相邻位置递推替代，降一维复杂度。

> 记住：**可变参数的个数 ≈ DP 表的维数**；参数取值范围 = 表的大小。

### 5. 单调栈套路
求"每个元素左/右第一个比它大（或小）的位置"：维护一个单调（递增或递减）栈，**违反单调性时弹栈结算**，弹出元素的答案 = 新入元素（右答案）+ 栈中下一个（左答案）。相等值用"位置列表"合并处理。是子数组最值类题的通用武器。

### 6. 滑动窗口 / 双指针
当 L 右移时 R 单调不回退（具有单调性），即可 O(N) 解决"窗口内最值 / 满足条件的子数组个数"。窗口最值用**单调双端队列**维护。

## 第一部分 排序、二分、位运算

### class01 排序基础 + 二分
| 文件 | 主题 | 复杂度 | 关键点 |
|---|---|---|---|
| SelectionSort | 选择排序 | O(n²)/O(1) | 每轮选最小放前 |
| BubbleSort | 冒泡排序 | O(n²)/O(1) | 异或交换注意 i≠j |
| InsertionSort | 插入排序 | O(n²)/O(1) | 唯一对"近乎有序"友好 |
| BSExist | 二分存在性 | O(logn)/O(1) | 中点防溢出 |
| BSNearLeft/Right | 二分边界 | O(logn)/O(1) | 找到不停、继续收缩记录 |
| BSAwesome | 无序找局部最小 | O(logn)/O(1) | 利用趋势，不需有序 |

### class02 位运算
- **Swap**：异或交换 `a^=b;b^=a;a^=b`，i==j 会清零。
- **EvenTimesOddTimes**：一个数出现奇数次→全异或；两个数→全异或得 `eor`，用 `eor & (-eor)` 取最低位 1 分组，再分别异或。
- **KM**：k 个数出现 m 次、其余出现 k 次——统计每个 bit 出现次数对 m 取模。O(n)。

### class04 归并排序及其衍生（**经典面试组**）
所有题都在 merge 过程中"顺手"统计，不破坏 O(n log n)。
- **MergeSort**：分到单元素再有序合并；非递归版注意步长溢出。
- **SmallSum（小和）**：merge 时 `arr[p1] < arr[p2]` 则 arr[p1] 对右组 `[p2,r]` 共 `(r-p2+1)` 个数产生小和。
- **ReversePair（逆序对）**：左 > 右时构成逆序对，从后往前统计。
- **BiggerThanRightTwice**：merge 前先用不回退的双指针统计 `arr[i] > 2*arr[j]`。

### class05 快排 + 区间和
- **CountOfRangeSum**：前缀和 + merge 时双滑动窗口控制上下界（LeetCode 327）。
- **PartitionAndQuickSort**：荷兰国旗三分（<, ==, >）；快排随机选 pivot 期望 O(n log n)。
- **QuickSort 递归/非递归**：非递归用栈存 (L,R) 区间。

### class06 堆与优先队列
- **Heap**：手写大根堆，核心 `heapInsert`（上浮）与 `heapify`（下沉）；索引：左 2i+1 / 右 2i+2 / 父 (i-1)/2。
- **HeapSort**：先 O(n) 建堆（从后往前 heapify），再不断弹最大值到末尾，原地 O(1) 额外空间。
- **SortArrayDistanceLessK**：近乎有序数组用容量 k 的小根堆，O(n log k)。
- **Comparator**：返回负→第一个在前。

### class08 前缀树 + 非比较排序
- **TrieTree**：`pass`/`end` 计数；删除时 `pass==0` 剪枝。Code01 的 prefixNumber 有 bug，Code02 为正确版。insert/search O(L)。
- **CountSort**：计数排序，值域 k，O(n+k)，仅非负整数。
- **RadixSort**：基数排序，从低位到高位每位用计数排序（稳定），O(d·n)。

## 第二部分 链表、栈、队列

### class03 栈队列结构
- **ReverseList**：pre/cur/next 三指针原地反转（单 + 双向）。
- **DeleteGivenValue**：先跳过开头要删的节点确定新 head，再 pre/cur 遍历。
- **DoubleEndsQueue**：双向链表实现栈和队列模板。
- **RingArray**：环形数组队列，`size==limit` 为满，nextIndex 取模循环。
- **GetMinStack**：双栈（数据栈 + 最小值栈），O(1) 取最小。
- **两栈实现队列 / 两队列实现栈**：倒数据；前者均摊 O(1)。

### class09 链表高级（**高频**）
- **LinkedListMid**：快慢指针，四种"中点"定义（上/下中点、中点前一个）要分清初始位置与循环条件。
- **IsPalindromeList**：终极版 O(1) 空间——找中点→反转后半→双向比对→**恢复链表**。
- **SmallerEqualBigger**：链表荷兰国旗，三段（小/等/大）各维护头尾再串联，注意空段处理。
- **CopyListWithRandom**：O(1) 空间版——在每个原节点后插入复制节点，设置 rand，再分离。

## 第三部分 二叉树

### class10 遍历
- 递归遍历（前/中/后）= 递归三个"时机"打印。
- **非递归遍历**：前序用栈直接模拟；中序压左边界；后序用两个栈（或单栈 + 前驱判断）。

### class11 树的衍生问题
- **LevelTraversal**：BFS 队列。
- **SerializeAndReconstruct**：前序/后序/层序都行（**用 null 占位**），**中序不可行**（结构歧义）。
- **EncodeNaryTree**：N 叉树 ↔ 二叉树 = "左孩子 - 右兄弟"。
- **TreeMaxWidth**：用 curEnd/nextEnd 标记层边界，**不需要 HashMap**。
- **SuccessorNode**（带 parent 指针求中序后继）：有右子树→右子树最左；否则向上找到"是父亲左孩子"的那个父亲。
- **PaperFolding**：折痕序列 = 一棵"左凹右凸"虚拟树的中序遍历。

### class12-13 二叉树判断 + 树形 DP（**树形 DP 套路集中营**）
全部用第零章「树形 DP 套路」：
- **IsCBT**（完全二叉树）：BFS 标记法 或 递归 4 个充要条件（结合满/完 + 高度关系）。
- **IsBST**：中序递增 或 递归带 min/max。
- **IsBalanced**：Info(isBalanced, height)，左右高度差 ≤ 1。
- **IsFull**：节点数 == 2^h − 1。
- **MaxSubBSTSize / MaxSubBSTHead**：Info(最大BST大小, 总大小, max, min[, 头节点])。
- **MaxDistance**：max(左距, 右距, 左高+右高+1)。
- **lowestAncestor（LCA）**：HashMap 存父 + Set 回溯 / 递归 Info(findA, findB, ans)。
- **MaxHappy（聚会快乐值）**：Info(来, 不来)，来→下属不来；不来→下属取 max。
- **LowestLexicography**：贪心比较器 `(a+b) vs (b+a)` 拼接字典序最小。

### class30 Morris 遍历（**O(1) 空间遍历，进阶亮点**）
- **MorrisTraversal**：利用左子树最右节点建临时回链，O(1) 空间 O(n) 时间；中序在 cur==null 时收集，前序在建链时收集，后序需逆序打印左边界。找最右循环条件 `mostRight.right != null && != cur` 防死循环。
- **MinHeight**：Morris 配合 rightBoardSize 回溯深度求最小高度。

## 第四部分 贪心、并查集、图

### class14 贪心 + 并查集
- **Light（路灯）**：遇未照亮的 `.` 在最右(+2)处放灯。
- **LessMoneySplitGold（分金条）**：小根堆每次合并最小两个 = 哈夫曼。O(n log n)。
- **BestArrange（会议安排）**：按**结束时间**排序贪心选不冲突的。
- **IPO**：双堆——成本小根堆筛出可做项目，丢进利润大根堆选最赚的，做 K 轮。
- **UnionFind**：路径压缩 + 按大小合并，近 O(1)。
> 贪心题面试做法：**写对数器，用暴力解验证贪心策略**，不要硬证。

### class15 并查集应用
- **FriendCircles**：union 所有认识的人数集合数。
- **NumberOfIslands**：DFS 感染 / 并查集（数组版最快）。
- **NumberOfIslandsII**：动态加点，用 HashMap 并查集支持稀疏，每次返回当前岛数。

### class16 图论
- 自定义 Graph/Node/Edge 模板。
- **BFS / DFS**：队列/栈 + HashSet 去重。
- **拓扑排序**：Kahn（入度为 0 入队）+ DFS 多版本。
- **Kruskal**（边排序 + 并查集判环）/ **Prim**（点扩张 + 堆选最小边）求最小生成树。
- **Dijkstra**：朴素 O(V²) / 手写可 decrease-key 的小根堆 O((V+E)logV)，无负权。

## 第五部分 递归与暴力枚举

### class17
- **Hanoi**：n 个 A→C = (n-1 个 A→B) + (1 个 A→C) + (n-1 个 B→C)，参数化方向最简洁。
- **PrintAllSubsequences**：每字符"要/不要"→ 2^n 子序列；去重用 HashSet。
- **PrintAllPermutations**：原地 swap + 回溯；用 visited 数组去重（分支限界）。
- **ReverseStackUsingRecursive**：递归函数 `f` 取出栈底元素，主递归反转。

## 第六部分 动态规划

> **务必结合第零章「暴力递归→DP 四步走」阅读。** 下面每题都先有暴力递归再优化。

### class18 入门
- **RobotWalk**：位置 1~N 走 K 步到 aim 的方法数。dp[位置][剩余步数]，边界只能单向。
- **CardsInLine（拿牌博弈）**：先手 `f(L,R)=max(arr[L]+g(L+1,R), arr[R]+g(L,R-1))`，后手 `g(L,R)=min(f(L+1,R), f(L,R-1))`。区间 DP 按长度填表。

### class19 经典模型
- **Knapsack（0-1 背包）**：dp[index][rest]，选/不选。O(N·W)。
- **ConvertToLetterString（数字转字母）**：'0' 不能单独转，组合需 <27。
- **StickersToSpellWord（贴纸拼词）**：词频数组 + HashMap 记忆化 + 贪心剪枝（选含目标首字符的贴纸）。
- **LongestCommonSubsequence（LCS）**：dp[i][j]，相等取对角线+1，否则 max(上,左)。

### class20 二维 / 区间 DP
- **PalindromeSubsequence（最长回文子序列）**：区间 DP dp[L][R]，或转化为"原串与逆串的 LCS"。
- **HorseJump（马跳）**：dp[x][y][rest]，8 方向。
- **Coffee（咖啡问题）**：堆贪心定喝完时间 + DP(index, 洗杯机空闲时刻) 求最早洗完。

### class21 矩阵 / 货币（**四种硬币问题要分清**）
- **MinPathSum**：dp[i][j] = 值 + min(上,左)，可压成一维。
- **CoinsWayEveryPaperDifferent**：每张不同（选/不选）。
- **CoinsWayNoLimit**：每种无限——优化式 `dp[i][rest]=dp[i+1][rest]+dp[i][rest-coin]`（消去枚举张数那一维）。
- **CoinsWaySameValueSamePaper**：同值张数有限——差值法优化。
- **BobDie（生存概率）**：dp[r][c][rest]，越界 0、rest==0 在界内为 1，除以 4^k。

### class22 优化
- **KillMonster（杀怪概率）**：dp[次数][血量]，**前缀和优化**消去枚举伤害维。
- **MinCoinsNoLimit**：最少硬币数，无解用 MAX 标记。
- **SplitNumber（数字不减拆分）**：dp[pre][rest]，`dp[pre][rest]=dp[pre+1][rest]+dp[pre][rest-pre]`。

### class23 回溯 / 约束
- **SplitSumClosed**：分两堆和最接近 = 在 sum/2 内做背包求最大。
- **SplitSumClosedSizeHalf**：限定个数 N/2，三维 dp[i][个数][rest]，奇数试两种大小。
- **NQueens**：递归逐行放 + 冲突检查；**位运算版**用 colLim/leftDia/rightDia，`pos = limit & (~limit)` 取最低位，极致优化。O(N!)。

### class26 矩阵快速幂（**严格递推 → O(logN)**）
- **FibonacciProblem**：任何**严格线性递推**都能写成矩阵幂，用快速幂 O(logN)。
- **ZeroLeftOneStringNumber**：不含连续 0 的 n 位串数 = 斐波那契式递推，可矩阵加速。

## 第七部分 滑动窗口与单调栈

### class24 窗口 / 双指针
- **SlidingWindowMaxArray**：单调双端队列存**下标**，队首为窗口最大值，过期弹出。O(N)。
- **AllLessNumSubArray**：max−min≤sum 的子数组个数；两个单调队列 + L 不回退，满足时 `+= R−L`。
- **GasStation（加油站）**：数组翻倍模拟环 + 前缀和 + 单调队列找区间最小。
- **MinCoinsOnePaper**：最少硬币数终极优化，按面值模分组 + 窗口最小值，O(N·aim)。

### class25 单调栈（**子数组最值类核心**）
- **MonotonousStack**：求每个元素左右第一个更小/更大值的模板，相等值用列表合并。
- **AllTimesMinToMax**：以每个数为最小值定左右边界 + 前缀和算最大"和×最小值"。
- **LargestRectangleInHistogram**：单调栈求直方图最大矩形。
- **MaximalRectangle**：逐行压成 height 数组复用直方图算法。
- **CountSubmatricesWithAllOnes**：逐行按高度层计数全 1 子矩阵。

### class26
- **SumOfSubarrayMinimums**：每个元素作为最小值的贡献 `(i-left)*(right-i)*arr[i]`；左用 `<=`、右用 `<` 避免重复计数。

- **IsRotation（旋转串）**：a 是 b 的旋转 ⟺ a 是 `b+b` 的子串，KMP O(N)。

### class28 Manacher（**最长回文 O(N)**）

## 第十部分 高级数据结构

### class31 线段树
- **SegmentTree**：sum + lazy（区间加）+ change/update（区间覆盖）；pushUp 合并、pushDown 下发；**覆盖优先级高于累加**，覆盖时清空 lazy。单次 O(logn)。
- **FallingSquares（掉落方块）**：坐标压缩 + 线段树区间最大值，查询后立即更新。

### class32 树状数组 + AC 自动机
- **IndexTree（树状数组）**：`index & -index` 取最低位 1；单点改 + 前缀和，O(logn)，比线段树简洁但仅支持加法、下标从 1 开始。
- **IndexTree2D**：二维前缀和，O(log²n)。
- **AC 自动机（AC1 计数 / AC2 返回串）**：Trie + fail 指针（BFS 构建，类比 KMP）做多模式匹配；沿 fail 链结算，用 end 标记防重复计数。

### class35-36 平衡树与跳表（**有序表三件套**）
- **AVLTreeMap**：节点存高度 h，失衡四型 LL/LR/RR/RL 旋转，maintain 沿路径向上维护。
- **SizeBalancedTreeMap（SB 树）**：节点存 size，四个平衡条件靠 size 比较；旋转后先更新新头 size；可按索引查（getIndexKey）。
- **SkipListMap（跳表）**：多层链表，`Math.random() < 0.5` 升层；从高层向下查找；期望 O(logn)，无旋转、实现最简。

**有序表选型对比：**

| 结构 | 查询 | 增删 | 特点 |
|---|---|---|---|
| 线段树 | O(logn) | O(logn) | 区间操作 + lazy，实现复杂 |
| 树状数组 | O(logn) | O(logn) | 最简洁，仅前缀和/加法 |
| AVL | O(logn) | O(logn) | 严格平衡，旋转频繁 |
| SB 树 | O(logn) | O(logn) | size 平衡，可按索引访问 |
| 跳表 | O(logn) 期望 | O(logn) 期望 | 无旋转，最易实现 |

### class37 有序表应用
- **CountofRangeSum**：前缀和 + 归并 / SB 树查 `[sum-upper, sum-lower]` 内节点数。
- **SlidingWindowMedian**：SB 树维护窗口，`getIndexKey((size-1)/2)` 取中位数；Node 按 value 再按 index 比较以容纳重复值。
- **AddRemoveGetIndexGreat**：SB 树**不按 key 而按插入位置**组织，实现 O(logn) 任意位置插/删/查（高级 ArrayList）。

## 附录 B 常见易错点清单

- 二分中点用 `L + ((R-L)>>1)`，找边界时**找到不停**继续收缩。
- 异或交换 `i==j` 会把值清零（数组同下标交换出 bug）。
- 取最低位 1：`x & (-x)` 等价 `x & (~x + 1)`。
- 链表题改指针前**先存 next**，回文/复制题做完要**恢复原结构**。
- 树形 DP 的 base case 返回 null 时，加工 Info 前要判空。
- 二叉树序列化**中序不可行**；反序列化必须用 null 占位。
- DP：**可变参数个数 = 表维数**；先写对暴力再改 DP，逻辑不要在改 DP 时变形。
- 硬币问题分清四类（每张不同 / 无限 / 同值有限 / 最少张数），优化式是 `dp[i][rest]` 依赖**同行** `dp[i][rest-coin]`。
- 单调栈子数组最值：**一侧用 `<=`、另一侧用 `<`** 防止重复计数。
- 滑动窗口最值队列里存的是**下标**不是值，注意过期判断。
- 线段树**区间覆盖优先级高于区间加**，覆盖时清 lazy；下发要按左右子树节点数分配。
- 树状数组下标**从 1 开始**，0 不用。
- 跳表升层是 `Math.random() < 0.5`（严格小于）。
- 贪心策略**靠对数器验证**，别在面试现场死磕证明。
